# Humanizer-ZH：AI 写作去痕工具

## 简介

Humanizer-zh 是一个专门用于去除文本中 AI 生成痕迹的工具，帮助你将 AI 生成的内容改写得更自然、更像人类书写的文本。本项目基于维基百科「AI 写作特征」页面（WikiProject AI Cleanup）的观察总结，能够识别并修复 **24 种** AI 写作痕迹，涵盖内容模式、语言语法、风格模式和交流模式四大类。

### 为什么 AI 写的中文读起来别扭？

AI 写的中文有一个核心问题：**骨架是英文的**。每一个字都是中文，每一处语法都合规，但句子的主谓搭配、动词选择、段落节奏，全是英文的。这股味道本质上是翻译腔——民国以来中国读者已经吐槽了一百年的老问题，只不过现在被 AI 批量生产出来了。

LLM 使用统计算法来猜测接下来应该是什么词。结果倾向于适用于最广泛情况的统计上最可能的结果。这导致 AI 生成的文本呈现出高度同质化的风格：过度正式、喜欢套话、充满翻译腔、缺乏具体细节。当你读一段 AI 写的中文，说不上哪个字错了，语法也对，意思也通，就是读起来别扭——这就是「AI 味」。

## AI 文案特征识别

### 1. 过度正式与翻译腔

AI 写中文时，像是先在英文的句法里把意思想清楚，再一个字一个字换成中文。句子的骨架留在英文里，只有皮被换成了中文词汇。

典型表现：

- **思考过程物理化**：把思考过程想象成物理动作。接住、击穿、拆解、锋利、不崩、撑不住、打穿、收紧、落地、推开、扛住——每一个都是英文动词的直译（catch、break through、decompose、sharp...），中文里没有这套生活经验，这些动词就悬空了
- **形容词起手式**：「逻辑很清晰：」「问题很直接：」「结论很明确：」「原因很简单：」——形容词先下判断，冒号引出内容。这抢走了读者自己评估的机会，而且形容词几乎总是多余的
- **抽象名词做主语**：「工程上的现实比这些数字难看」——英文原型 "The reality is uglier than..."，中文读者读完「难看」就停在那了，不知道到底是什么在错位
- **中英夹杂**：context、state、cache、claim 这些词都有现成的中文对译，AI 却让英文单词原样留下，读者要在脑子里反复切换

### 2. 套话与空洞表达

AI 最擅长用大词填充，却很少提供具体信息：

| AI 套话 | 问题 |
|---------|------|
| 作为……的证明/体现 | 夸大象征意义 |
| 标志着……的关键时刻 | 无意义的拔高 |
| 不断演变的格局 | 空洞的宏观叙事 |
| 为……奠定坚实基础 | 缺乏具体支撑 |
| 致力于/赋能 | 互联网黑话，空洞承诺 |
| 充满活力的/丰富的 | 夸张的宣传性语言 |

### 3. 公式化结构

AI 特别喜欢几种固定结构，几乎出现在每一段输出中：

- **三段式法则**：强行把想法分成三组以显得全面。「创新、灵感和行业洞察」「主题演讲、小组讨论和社交机会」
- **否定式排比**：「不仅……而且……」「这不仅仅是关于……而是……」被过度使用
- **首先/其次/最后/综上所述**：连续段落以这种模板开头
- **挑战与未来展望**：公式化的收尾段落

### 4. 高频 AI 词汇警示

以下词汇在 2023 年后的 AI 生成文本中出现频率异常高，它们经常共同出现：

**连接词类**：此外、然而、与此同时、值得注意的是、需要指出的是

**拔高词类**：至关重要、深入探讨、持久的、增强、培养、突出、彰显、关键性的、充满活力的、织锦（抽象用法）、宝贵的

**动词替换类**：展示、体现、致力于、促进、推动、探索、引领

**互联网黑话类**：赋能、抓手、中台、闭环、落地、漏斗、沉淀、对齐、对标、迭代、优化、聚焦、倒逼、复盘、梳理、输出、提炼

## 自然化规则

### 规则一：删除填充短语

去掉开场白和强调性拐杖词，直接说事。

| 改写前 | 改写后 |
|--------|--------|
| 为了实现这一目标 | 为了实现这一点 |
| 由于下雨的事实 | 因为下雨 |
| 在这个时间点 | 现在 |
| 在您需要帮助的情况下 | 如果您需要帮助 |
| 系统具有处理的能力 | 系统可以处理 |
| 值得注意的是数据显示 | 数据显示 |
| 需要指出的是 | （直接删除） |

### 规则二：打破公式结构

避免二元对比、戏剧性分段、修辞性设置。

**改写前：**
> 这不仅仅是节拍在人声下流动；它是攻击性和氛围的一部分。这不仅仅是一首歌，而是一种声明。

**改写后：**
> 沉重的节拍增加了攻击性的基调。

**改写前：**
> 活动包括主题演讲、小组讨论和社交机会。与会者可以期待创新、灵感和行业洞察。

**改写后：**
> 活动包括演讲和小组讨论。会议之间还有非正式社交的时间。

### 规则三：变化节奏

混合句子长度。两项优于三项。段落结尾要多样化。

**改写前（所有句子等长）：**
> 实验产生了有趣的结果。智能体生成了 300 万行代码。一些开发者印象深刻，另一些则持怀疑态度。影响尚不明确。

**改写后（长短交错）：**
> 300 万行代码，在人类大概睡觉的时候生成的。开发社区有一半人疯了，另一半人在解释为什么这不算数。真相可能在无聊的中间某处。

### 规则四：信任读者

直接陈述事实，跳过软化、辩解和手把手引导。

**改写前：**
> 虽然关于公司成立的具体细节在现成资料中没有广泛记录，但它似乎是在 20 世纪 90 年代的某个时候成立的。

**改写后：**
> 根据注册文件，该公司成立于 1994 年。

### 规则五：删除金句

如果听起来像可引用的语句，重写它。

**改写前：**
> 人工智能不仅仅是一种技术，它是我们思考未来的方式的革命。

**改写后：**
> AI 正在改变人们思考未来的方式。

### 规则六：用「是」和「有」替代复杂结构

LLM 习惯用复杂结构替代简单的系动词。

**改写前：**
> Gallery 825 作为 LAAA 的当代艺术展览空间。画廊设有四个独立空间，拥有超过 3000 平方英尺。

**改写后：**
> Gallery 825 是 LAAA 的当代艺术展览空间。画廊有四个房间，总面积 3000 平方英尺。

### 规则七：消除翻译腔的四类套路

1. **思考过程物理化**：接住→收到/同意；击穿→解决；锋利→清楚；不崩→稳定
2. **形容词起手式**：「逻辑很清晰：XXX」→ 直接写 XXX
3. **抽象名词主语**：「X 的 Y 比 Z 更 W」→ 让人、动作或具体对象做主语
4. **中英夹杂**：context→上下文；state→状态；cache→缓存；claim→断言

### 规则八：具体细节替代空洞主张

**改写前：**
> 坐落在埃塞俄比亚贡德尔地区令人叹为观止的区域内，Alamata Raya Kobo 是一座充满活力的城镇，拥有丰富的文化遗产和迷人的自然美景。

**改写后：**
> Alamata Raya Kobo 是埃塞俄比亚贡德尔地区的一座城镇，以其每周集市和 18 世纪教堂而闻名。

**改写前：**
> 寺庙的蓝色、绿色和金色色调与该地区的自然美景产生共鸣，象征着德克萨斯州的蓝帽花、墨西哥湾和多样化的德克萨斯州景观，反映了社区与土地的深厚联系。

**改写后：**
> 寺庙使用蓝色、绿色和金色。建筑师表示这些颜色是为了呼应当地的蓝帽花和墨西哥湾海岸。

## 使用方法

### 安装

```bash
# 方法一：通过 npx 一键安装（推荐）
npx skills add op7418/humanizer-zh --skill humanizer-zh

# 方法二：通过 Git 克隆
git clone https://github.com/op7418/Humanizer-zh.git
# 将 Humanizer-zh 文件夹复制到 ~/.claude/skills/ 目录

# 验证安装：重启 Claude Code 后输入
/humanizer-zh
```

### 基础用法

**1. 直接调用技能**

```
/humanizer-zh 请帮我人性化以下文本：
[粘贴你的 AI 生成文本]
```

**2. 在对话中使用**

```
请用 humanizer 帮我改写这段话，让它更自然：
这个项目作为我们团队致力于创新的证明。此外，它展示了我们在不断演变的技术格局中的关键作用。
```

**3. 处理文件内容**

```
/humanizer-zh 请人性化 article.md 文件中的内容
```

### 处理流程

1. 仔细阅读输入文本
2. 识别 24 种 AI 模式的实例
3. 重写每个有问题的部分
4. 确保修订后的文本大声朗读时听起来自然，自然地变化句子结构，使用具体细节而不是模糊主张，为上下文保持适当的语气
5. 呈现人性化版本

### 质量评分

对改写后的文本进行 1-10 分评估（总分 50）：

| 维度 | 评估标准 |
|------|----------|
| 直接性 | 直接陈述事实还是绕圈宣告？10 分：直截了当；1 分：充满铺垫 |
| 节奏 | 句子长度是否变化？10 分：长短交错；1 分：机械重复 |
| 信任度 | 是否尊重读者智慧？10 分：简洁明了；1 分：过度解释 |
| 真实性 | 听起来像真人说话吗？10 分：自然流畅；1 分：机械生硬 |
| 精炼度 | 还有可删减的内容吗？10 分：无冗余；1 分：大量废话 |

评分标准：45-50 分优秀；35-44 分良好；低于 35 分需要重新修订。

## 不同场景的处理

### 营销文案

营销文案最容易沾染 AI 味，因为 AI 天然倾向于夸大和宣传性语言。

**改写前：**
> 坐落在风景如画的杭州市中心，这家咖啡馆拥有丰富的文化底蕴和令人叹为观止的装饰。它作为城市咖啡文化的焦点，为顾客提供无缝、直观和充满活力的体验。

**改写后：**
> 这家咖啡馆在杭州市中心开了三年，以手冲咖啡和老建筑改造的空间出名。

处理要点：
- 删除「坐落于」「令人叹为观止」「充满活力」等宣传性用词
- 替换为具体事实：开了几年、以什么出名、特色是什么
- 「无缝、直观和强大」这类三段式描述改为实际体验描述

### 学术/技术文档

学术文档的 AI 味主要表现为模糊归因和公式化结构。

**改写前：**
> 本研究深入探讨了机器学习在医疗诊断中的关键作用，突出了其在不断演变的医疗格局中的重要性。此外，它为该领域的未来发展奠定了坚实的基础。

**改写后：**
> 本研究分析了机器学习在医疗诊断中的应用，重点是肺癌早期筛查。研究使用了 2019-2023 年间 5000 例病历数据。

处理要点：
- 「深入探讨」→ 直接说研究了什么
- 「关键作用」「不断演变的格局」→ 删除空洞拔高
- 补充具体数据和方法
- 模糊归因（「专家认为」）→ 给出具体来源

### 自媒体/博客

自媒体最需要个人声音，而 AI 最缺的就是这个。

**改写前：**
> 人工智能不仅仅是一种技术，它是我们思考未来的方式的革命。行业专家认为这将对整个社会产生持久影响。

**改写后：**
> 我一直在想 AI 会怎么改变我们的工作方式。上周和几个做产品的朋友聊，有人觉得很兴奋，有人担心失业，大概率真相在中间某个无聊的地方。

处理要点：
- 加入第一人称视角（「我一直在想……」「让我困扰的是……」）
- 承认复杂性和不确定性（「大概率真相在中间」）
- 允许口语化表达和不完美的结构
- 加入具体场景和细节（「上周和朋友聊」）

### 正式写作

正式写作需要去除 AI 味但保持专业度，不能过于随意。

**改写前：**
> 此外，索马里菜肴的一个显著特征是加入骆驼肉。意大利殖民影响的持久证明是当地烹饪格局中广泛采用意大利面，展示了这些菜肴如何融入传统饮食。

**改写后：**
> 索马里菜肴还包括骆驼肉，被认为是一种美味。在意大利殖民期间引入的意大利面菜肴仍然很常见，尤其是在南部。

处理要点：
- 保持正式但不僵化
- 删除「此外」「持久证明」「格局」等 AI 词汇
- 用陈述句替代分析性框架
- 保留必要的专业术语

## 最佳实践

### 不仅要去 AI 味，更要注入灵魂

无菌、没有声音的写作和机器生成的内容一样明显。好的写作背后有一个真实的人。

**缺乏灵魂的迹象：**
- 每个句子长度和结构都相同
- 没有观点，只有中立报道
- 不承认不确定性或复杂感受
- 适当时不使用第一人称视角
- 没有幽默、没有锋芒、没有个性
- 读起来像维基百科文章或新闻稿

**如何增加语调：**
- **有观点**：「我真的不知道该怎么看待这件事」比中立地列出利弊更有人味
- **变化节奏**：短促有力的句子。然后是需要时间慢慢展开的长句。混合使用
- **承认复杂性**：「这令人印象深刻但也有点不安」胜过「这令人印象深刻」
- **适当使用「我」**：第一人称不是不专业——而是诚实
- **允许一些混乱**：完美的结构感觉像算法。跑题、题外话和半成型的想法是人性的体现
- **对感受要具体**：不是「这令人担忧」，而是「凌晨三点没人看着的时候，智能体还在不停地运转，这让人不安」

### 快速自检清单

改写完后，逐项检查：

- 连续三个句子长度相同？打断其中一个
- 段落以简洁的单行结尾？变换结尾方式
- 揭示前有破折号？删除它
- 解释隐喻或比喻？相信读者能理解
- 使用了「此外」「然而」等连接词？考虑删除
- 三段式列举？改为两项或四项

### 批量处理策略

处理长文档时建议分段进行：

1. 第一遍：只圈出四类翻译腔套路（物理化动词、形容词起手式、抽象名词主语、中英夹杂）
2. 第二遍：逐处修改圈出的内容
3. 第三遍：通读全文，检查节奏和连贯性

## 注意事项

### 何时不应使用

- **技术规格/接口文档**：这类文档需要精确性和一致性，AI 的公式化结构反而是优点
- **法律合同/合规文本**：正式性和一致性比「自然」更重要
- **需要保留技术准确性的内容**：不要为了「自然」而牺牲术语的准确性
- **学术论文的 Method/Results 部分**：科研写作有其规范，不应为了去 AI 味而偏离学术惯例

### 保持技术准确性

去 AI 味不是简单地「说人话」，核心是**让信息更有效传达**。改写时必须：

- 保留所有事实和数据
- 不改变原文的核心论点
- 专业术语保持原样（不要把「异步 I/O」改成「不同步读写」）
- 引用和出处不能省略

### 适度原则

过度去 AI 味同样有问题：

- 不要为了口语化而牺牲清晰度
- 不要为了「有个性」而加入不必要的个人表达
- 不要把所有长句都拆成短句——长短交错才是目标
- 不是所有「此外」都要删——有时它确实是最合适的连接词

### 本工具的定位

这个工具不是为了「欺骗」AI 检测器，而是为了真正提升写作质量。最好的「去 AI 化」方法是让文字有真实的人类思考和声音。技术手段只是辅助，核心还是写作者自己对内容的理解和判断。
