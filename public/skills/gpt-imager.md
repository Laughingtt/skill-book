# GPT Imager（生图）

## 简介

GPT Imager 是一个专为 AI 代理设计的图像生成技能，通过优化提示词来驱动 OpenAI 的 DALL-E / GPT Image 系列模型生成高质量图片。它将自然语言描述转化为结构化、精准的图像生成提示词，大幅提升出图的准确性和视觉表现力。

OpenAI 的图像生成模型已经从 DALL-E 2 演进到 DALL-E 3、gpt-image-1 以及最新的 gpt-image-2。每一代模型在提示词理解、细节渲染和文本嵌入能力上都有显著提升。GPT Imager 技能帮助用户掌握这些模型的特点，写出更有效的提示词，从而获得更理想的图像输出。

核心价值：

- **提示词优化**：将模糊的描述转化为精准、结构化的图像提示词
- **风格控制**：通过关键词精确控制输出图像的艺术风格、媒介和视觉质感
- **构图引导**：利用构图术语引导画面布局和视觉焦点
- **光照与色彩**：指定光照类型和色彩方案，塑造画面氛围

## 图像生成基础

### 支持的模型

| 模型 | 特点 | 适用场景 |
|------|------|----------|
| DALL-E 3 | 提示词理解力强，支持 `vivid`/`natural` 风格参数 | 通用图像生成，风格化插画 |
| gpt-image-1 | 自回归架构，支持文本渲染和图像编辑 | 需要图中文字、多图融合 |
| gpt-image-2 | 原生 4K 输出，质量更高，成本更低 | 高分辨率需求，商业素材 |

### 图像尺寸

**DALL-E 3 尺寸选项：**

- `1024x1024` — 正方形，适合头像、图标、社交媒体
- `1792x1024` — 横版（约 16:9），适合横幅、文章配图、演示文稿
- `1024x1792` — 竖版（约 9:16），适合手机壁纸、海报、故事封面

**gpt-image-2 尺寸选项：**

- 支持 1K / 2K / 4K 分辨率档位
- 最大输出 3840x2160（4K），无需额外放大流程
- 支持 5:4、1:1、16:9 等多种宽高比

### 质量参数

- **quality**：控制图像细节丰富度和提示词遵循度，与分辨率无关
  - `low` — 快速出图，细节较少，不适合含文字的图像
  - `medium` — 平衡速度与质量，适合日常素材
  - `high` — 最高细节，适合最终交付素材和含小文字的图像

- **style**（仅 DALL-E 3）：
  - `vivid`（默认）— 色彩鲜明、戏剧性强的超写实风格
  - `natural` — 更自然、低饱和度，接近真实摄影效果

## 提示词工程

### 提示词结构

一个高效的图像提示词遵循从整体到细节的层次结构：

```
[媒介/类型] + [主体描述] + [环境/背景] + [光照] + [构图] + [风格/氛围] + [技术参数]
```

**示例拆解：**

```
数码插画 / 一只穿宇航服的猫坐在月球表面 / 背景是蓝色地球和星空 / 柔和的侧光 /
特写构图 / 皮克斯动画风格，温暖色调 / 4K，细节丰富
```

### 核心原则

1. **具体胜于抽象**：不说"美丽的风景"，而说"秋日黄昏的日本寺庙，红枫映衬金色夕阳"
2. **指定数量**：不说"人们"，而说"三个人"；不指定时模型可能填充过多人物
3. **描述而非否定**：不说"不要文字"，而说"纯视觉图像，无文字元素"。否定词常被忽略甚至产生反效果
4. **层次分明**：先定义最重要的主体，再补充环境和细节
5. **迭代优化**：首次生成后根据结果调整关键词，逐步逼近目标

### 关键词分类

| 类别 | 示例关键词 |
|------|-----------|
| 媒介 | 照片、油画、水彩、数码插画、3D 渲染、像素画、素描、剪纸 |
| 画幅 | 特写、半身像、全景、鸟瞰、仰视、鱼眼 |
| 光照 | 黄金时刻、影棚灯光、霓虹灯、逆光、伦勃朗光、烛光 |
| 氛围 | 梦幻、赛博朋克、极简、复古、童话、暗黑 |
| 质量 | 4K、细节丰富、超高清、电影感、获奖作品 |

## 风格控制

### 写实摄影

```
专业摄影，[主体]，[场景]，[光照条件]，[镜头描述]，[胶片/传感器风格]
```

关键提示词：`35mm 镜头`、`景深`、`f/1.8`、`自然光`、`RAW 照片`、`胶片颗粒感`、`人像摄影`

**示例：**
```
专业人像摄影，一位戴圆框眼镜的女性坐在咖啡厅窗边，
午后自然光从左侧照入，浅景深，富士胶片色调，温暖氛围
```

### 插画 / 绘画

```
[绘画媒介] 风格的 [主体]，[艺术参考]，[色调]
```

可选媒介：`水彩画`、`油画`、`丙烯画`、`彩色铅笔`、`炭笔素描`、`版画`、`浮世绘`

**示例：**
```
水彩画风格的江南水乡，小桥流水人家，
烟雨朦胧，淡雅的中国传统色彩，留白构图
```

### 3D 渲染

```
3D 渲染，[主体]，[材质描述]，[渲染引擎]，[光照模式]
```

关键提示词：`Octane 渲染`、`Blender`、`Cinema 4D`、`等距视角`、`低多边形`、`PBR 材质`

**示例：**
```
3D 等距渲染，一个微型图书馆场景，暖木材质书架，
柔和的环境光遮蔽，Octane 渲染，糖果色系，细节丰富
```

### 像素艺术

```
像素画，[主体]，[分辨率]，[调色板]，[游戏风格参考]
```

关键提示词：`16x16`、`32x32`、`8-bit`、`16-bit`、`NES 风格`、`SNES 风格`

**示例：**

## 构图与布局技巧

### 构图法则提示词

| 构图类型 | 英文术语 | 提示词写法 |
|----------|---------|-----------|
| 三分法 | Rule of thirds | "主体位于画面左侧三分之一处" |
| 中心构图 | Center composition | "主体居中，对称构图" |
| 引导线 | Leading lines | "道路引导视线指向远方的山" |
| 框架构图 | Frame within frame | "透过拱门看到远处的风景" |
| 前景层次 | Foreground interest | "近处花朵虚化，远处山脉清晰" |

### 视角控制

```
# 鸟瞰
鸟瞰视角，[场景俯视描述]

# 仰视
低角度仰视，[主体从下方观察的描述]

# 平视
平视视角，[主体与视线齐平的描述]

# 荷兰角
荷兰角倾斜构图，[不安或动感的场景描述]
```

### 人物数量与位置

- 明确指定人数："画面中有两位女性"
- 指定相对位置："左侧一位男性，右侧一位女性，面向彼此"
- 不指定人数时，模型倾向于填充大量人物，务必显式声明

## 色彩与光照控制

### 光照类型

| 光照 | 提示词 | 效果 |
|------|--------|------|
| 黄金时刻 | `黄金时刻光线`、`日落侧光` | 暖色调，长阴影，温暖氛围 |
| 蓝色时刻 | `蓝色时刻`、`暮光` | 冷色调，柔和均匀，宁静感 |
| 影棚 | `影棚灯光`、`伦勃朗光`、`环形灯` | 专业感，可控阴影 |
| 戏剧性 | `明暗对比`、`剪影`、`聚光灯` | 强烈情绪，高反差 |
| 霓虹 | `霓虹灯光`、`彩色LED` | 赛博朋克感，高饱和 |
| 自然 | `漫射自然光`、`阴天柔和光` | 柔和无硬阴影 |

### 色彩方案

在提示词中直接指定色彩倾向：

```
# 单色系
"以深蓝色为主色调的单色画面"

# 互补色
"橙紫色互补色方案，暖冷对比"

# 类似色
"蓝绿色系渐变，海洋色调"

# 限定调色板
"仅使用珊瑚红、薄荷绿和奶油白三色"
```

## 常见问题与限制

### 提示词被改写

ChatGPT 中的 DALL-E 会自动扩展和改写用户的提示词。API 调用则更忠实于原始提示词。如需精确控制，建议使用 API 并在提示词开头加上"请严格按以下描述生成图像，不要修改内容"。

### 文字渲染

- gpt-image-1 / gpt-image-2 的文字渲染能力优于 DALL-E 3
- 简短英文文字渲染效果较好，中文文字容易出现错误
- 使用 `quality: high` 可提升文字准确性
- 尽量将需要渲染的文字放在提示词中用引号标出

### 人脸和手部

AI 图像生成模型在人脸细节和手部结构上仍有限制，可能出现：
- 手指数量异常
- 面部五官不对称
- 多人场景中面部模糊

应对策略：使用特写或半身构图，避免展示完整手部，或指定"双手自然放在身侧"。

### 版权与安全限制

- 无法生成真实公众人物的可识别肖像
- 无法生成暴力、色情等违规内容
- 无法复制受版权保护的商标和角色设计
- 生成的图像根据 OpenAI 使用条款享有相应权利

### 一致性挑战

同一提示词多次生成可能产生不同结果。保持一致性的方法：
- 在提示词中固定风格关键词（如"同前述风格"）
- 使用种子参数（API 支持）
- 在 ChatGPT 中持续对话，让模型记住上下文

## 最佳实践

1. **先确定用途再写提示词**：封面图、社交媒体、报告插图各有不同的尺寸和风格需求
2. **从简单开始，逐步细化**：先用核心主体生成，再根据结果补充细节关键词
3. **建立个人关键词库**：记录每次成功生成时使用的风格、光照和构图关键词
4. **善用参考艺术家**：指定"莫奈风格"、"宫崎骏风格"等可快速锁定视觉方向
5. **批量迭代**：同一提示词生成多次，挑选最佳结果，再基于该结果优化
6. **注意宽高比匹配用途**：横版用于文章配图，竖版用于手机素材，方形用于头像图标
7. **避免过度堆砌关键词**：提示词过长可能导致模型混淆，保持在 3-5 个核心维度
8. **使用否定提示词时谨慎**：DALL-E 对否定词的理解不可靠，优先使用正面描述
9. **API 与 ChatGPT 差异**：API 输出更忠实于提示词但质量可能略低，ChatGPT 会自动优化提示词
10. **保存成功提示词模板**：将效果好的提示词结构化为模板，替换主体部分即可复用
