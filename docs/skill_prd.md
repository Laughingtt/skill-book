# Skill 手册系统 PRD（增强版：含原型与技术设计）

## 一、产品概述
本产品是一个本地运行的 Skill 知识库系统，用于结构化管理和检索 AI Skill。

目标：
- 提供统一 Skill 查询入口
- 支持结构化管理与扩展
- 本地运行，轻量可维护

---

## 二、用户与场景
用户：
- AI开发者 / 工程师
- Prompt工程师

核心场景：
- 快速查找 skill 用法
- 学习 skill 使用场景
- 作为工具参考手册

---

## 三、功能需求

### 1. Skill 浏览
- Markdown 渲染
- 展示结构化信息

### 2. 搜索
- 模糊搜索（名称/标签/内容）

### 3. 分类过滤
- 自动生成分类
- 点击筛选

### 4. 标签过滤
- 多标签筛选

### 5. Skill详情页
- 独立路由展示

## 六、技术设计

### 技术栈

前端：
- Vue3
- Vite

解析：
- markdown-it

搜索：
- fuse.js

---

### 数据流

1. 读取 /public/skills/*.md
2. 解析 frontmatter
3. 转换为 JS 对象
4. 构建搜索索引
5. 渲染 UI

---

### 核心模块

#### 1. parser
- 解析 markdown + meta

#### 2. search
- fuse.js 索引

#### 3. store（简单状态）
- skills
- filteredSkills

---

### 路由设计

/                首页
/skill/:name     详情页

---

### 状态管理（轻量）

使用：
- Vue ref/reactive

无需 Vuex/Pinia（初期）
